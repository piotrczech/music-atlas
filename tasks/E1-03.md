# Audio, annotation and licence audit

Audit the downloaded catalogue for decoding failures, empty or unusually short recordings,
metadata mismatches and repeated audio. Use exact hashes for identical files and a documented
fingerprint or targeted check for likely re-encodings; distinguish confirmed duplicates from
candidates. Record outcomes by track ID, including the reason for each exclusion and a stable
duplicate-group identifier. Examine how genre annotations and licence information are populated.

The split-building task will use this audit to keep related recordings together, while the
application will need a small set of distributable listening examples. Produce a concise summary
of usable coverage, unresolved cases and the licence-selection rule for those examples. Retain
the source files and make exclusions explicit rather than silently dropping records.
