# Shared audio loader and deterministic windows

Implement the research audio loader used by feature extraction, spectrogram generation and
pretrained encoders. It should read a requested offset and duration without decoding an entire
long recording into memory, convert channels consistently, and resample to an explicit target
rate. Implement deterministic beginning/middle/end window selection for the full profile and a
single-window policy for quick runs, including a documented rule for short recordings and
overlapping windows.

Return the track/window identifiers and actual time bounds with the samples so that
representations can be aligned later. Keep encoder-specific rate requirements configurable while
sharing window positions. Check stereo input, short and silent recordings, invalid samples and
decoding failures; extraction commands must be able to report a bad track and continue with the
catalogue.
