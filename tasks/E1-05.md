# Versioned dataset splits and genre mapping

Create the canonical track manifest by combining the catalogue, audit results and genre
metadata. Inspect the published FMA split, then construct a reproducible artist-disjoint
train/validation/test partition that also keeps confirmed duplicate groups together. Resolve any
duplicate group spanning multiple artists as one split unit. Define how missing artist IDs and
sparse genre classes are handled, and fix the genre-to-column mapping and hierarchy propagation
rule used by all classifiers.

Save the manifest with the fields specified in the experimental protocol, a version/hash and
per-split class-support statistics. Check artist and duplicate-group overlap programmatically.
This partition is shared by every representation, so model-specific filtering must be recorded
without changing the underlying split or moving difficult examples between partitions.
