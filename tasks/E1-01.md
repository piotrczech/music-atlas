# Repository setup and initial WCSS configuration

Establish the shared development environment and verify that the repository runs both locally
and on the team's WCSS account. Review the existing package, uv lockfile and quick/full
profiles, configure the allocated PD directories, and keep dataset files, environments and
caches outside home storage. Confirm the account, partition, GPU type and compatible
driver/PyTorch stack. Run the supplied CPU smoke job and record the account-independent commands
in the development guide.

This provides the execution environment used by the data and modelling tasks. Keep personal
paths and credentials out of Git, retain one code path for local and cluster execution, and
resolve installation or storage issues before the team starts full-dataset processing.
