# FMA-full download and catalogue preparation

Implement a repeatable command for downloading FMA-full and its metadata to the configured data
directory on WCSS. Verify the published checksums, extract the archive into a stable directory
layout, and build an inventory linking FMA track IDs to relative audio paths. Report missing or
unexpected files and make an interrupted download or extraction recoverable without starting the
entire process again.

Plan the temporary disk footprint before transferring the archive: the compressed download,
extracted audio, environments and caches must fit within the 2 TB allocation. Preserve the
original audio format. This inventory becomes the input to the dataset audit and manifest
construction, so avoid embedding machine-specific absolute paths in saved records.
