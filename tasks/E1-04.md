# Metadata exploration and genre distributions

Explore the FMA metadata and prepare a compact set of figures describing genre frequencies,
label co-occurrence, artist and album concentration, track durations and annotation coverage.
Include the genre hierarchy so that a heavily populated parent category is distinguishable from
its more specific children. Work from track IDs and save the analysis so that it can be rerun
after the file audit updates the usable catalogue.

Use the results to identify rare classes, missing metadata and concentrations that could distort
training or evaluation. Summarise the implications for the label set and split strategy in a
short interpretation accompanying the figures. These outputs will support the experimental
protocol and later dataset-exploration view.
